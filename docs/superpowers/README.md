# Design plans (historical)

The design spec and two implementation plans written in October 2026 for the About logo wall and the Pages CMS content-editing work. They record why those changes were made and are kept for reference only.

They are not kept up to date. For example, they say content edits always wait for production approval, but content-only edits now publish automatically (see `deploy/CI.md`). For how the site works today, read the main `README.md` and `docs/content-editing.md`.
